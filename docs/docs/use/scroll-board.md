# 比赛滚榜

滚榜指比赛结束后，将封榜期间隐藏的提交结果按时间顺序逐步「揭开」、动态刷新榜单的展示过程，常用于颁奖环节。

:::tip
使用滚榜需同时满足以下条件：

- 比赛为 **ACM 赛制**
- 比赛已**结束**
- 比赛配置了**封榜**
:::

## 一、创建或修改比赛

配置比赛为 **ACM 赛制**，同时点击开启封榜并设置封榜时长。建议一并开启「**比赛结束后继续封榜**」，避免比赛一结束榜单自动刷新，却还没来得及滚榜。

![创建或修改比赛](/scrollBoard_create.png)

## 二、进入比赛并开始滚榜

进入比赛页面，点击导航栏的「滚榜」按钮。先确认比赛的金、银、铜牌数量是否正确，然后点击「**开始滚榜**」跳转到滚榜界面。

![进入比赛](/scrollBoard_start.png)

## 三、滚榜演示

进入滚榜页面后，逐次按下 **回车键** 即开始滚榜——每按一次，揭开一批封榜期间的提交并刷新排名，直到榜单完全揭晓。

![滚榜演示](/scrollBoard_show.png)

:::warning
滚榜数据依赖封榜期间保留的提交记录，因此务必在封榜后、滚榜前保持「比赛结束后继续封榜」开启，否则榜单会被提前刷掉。
:::

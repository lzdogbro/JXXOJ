# 导入用户

:::info
用户批量导入仅超级管理员可操作，入口位于后台管理「用户列表」页面的导入按钮。
:::

![用户导入](/338bf9db257844a1b32a4ff54c6528f6.png)

## 一、CSV 格式要求

:::tip
1. 仅支持 **CSV** 格式的用户数据文件。
2. 共 **7 列**，按固定顺序排列；其中「用户名」「密码」不能为空，其余列可留空。
3. **不需要写表头行**（第一行直接是数据）。
4. 性别取值：男 `male` 或 `0`，女 `female` 或 `1`，不填默认为 `secrecy`。
5. 请保存为 **UTF-8 编码**，否则中文可能乱码。
:::

列顺序如下：

| 列序 | 字段     | 必填 | 说明               |
| ---- | -------- | :--: | ------------------ |
| 1    | 用户名   |  ✔   | 登录账号           |
| 2    | 密码     |  ✔   | 登录密码           |
| 3    | 邮箱     |      | 可选填             |
| 4    | 真实姓名 |      | 可选填             |
| 5    | 性别     |      | male/0、female/1   |
| 6    | 昵称     |      | 可选填             |
| 7    | 学校     |      | 可选填             |

## 二、CSV 示例

```csv
zhangsan,123456,zhangsan@example.com,张三,male,小张,某某大学
lisi,123456,,李四,female,,某某大学
wangwu,123456,,,,,
```

- 第 1 行：完整填写全部 7 列。
- 第 2 行：邮箱、真实姓名、昵称留空，其余填写。
- 第 3 行：仅填写用户名与密码（性别留空则默认为 `secrecy`）。

> 各字段之间用英文逗号 `,` 分隔；若字段内容本身包含逗号或换行，请按 CSV 规范用双引号包裹。

## 三、注意事项

- 用户名需全局唯一，重复的用户名会导致该行导入失败。
- 导入前建议先用少量数据试跑，确认列顺序与编码无误后再批量导入。
- 导入成功后，用户即可使用对应的用户名与密码登录。

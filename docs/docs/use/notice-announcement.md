# 通知和公告发布

:::tip
1. 通知和公告均仅**超级管理员**可操作。
2. **公告**：展示在网站首页公告栏，用户主动查看。
3. **通知**：属于系统消息，由系统**定时推送**到用户的站内消息中心，用于主动触达用户。
:::

## 一、发布公告

在后台「系统公告管理」中新增公告，填写标题与内容（支持 Markdown）后发布。公告发布后会展示在首页公告栏，供所有用户浏览。

![公告管理](/b2e1edf697494ed68c760beb63b782bf.png)

## 二、推送通知

在后台「系统通知」中新建通知，选择通知类型与接收对象：

- **全部用户（All）**：推送给所有用户。
- **指定用户（Single）**：仅推送给指定的单个用户。
- **管理员（Admin）**：仅推送给管理员角色。

通知保存后，由系统定时任务推送到目标用户的站内消息中心。

![通知管理](/fe1cf4b8c0174933b8ffc8f17a486b53.png)

:::info
站内消息系统会定时刷新，用户收到新消息后会在页面右上角出现角标提示，进入「消息中心」即可查看系统通知。
:::

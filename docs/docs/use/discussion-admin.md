# 评论管理

评论（讨论）管理指后台管理员对全站讨论帖及其评论、举报的审核与治理。入口位于后台管理的「讨论管理」页面。

![评论管理](/6fcdb9f6895043498cb9d4bbadeb0a5b.png)

## 一、功能说明

:::tip
- 查看所有讨论帖（含公共讨论区、题目讨论、比赛讨论）
- 对讨论帖进行**置顶**、**显示/隐藏**、**删除**等操作
- 查看并处理对应讨论帖的**举报**内容
- 对违规评论、回复进行封禁或删除
:::

## 二、讨论列表

后台讨论列表会展示每篇讨论的标题、作者、所属分类、点赞/评论数、置顶状态等信息，管理员可在此快速筛选与定位。

![讨论列表](/20210523221321418.png)

## 三、举报处理

用户举报讨论或评论后，管理员可在后台查看举报内容与被举报对象，据此决定是否隐藏或删除对应内容。

> 与讨论相关的角色权限说明，请参考 [用户管理](/use/admin-user/) 中的「讨论管理」权限行。
